# SmartCare - Clinic Management System

## Installation
1. Install Python 3.10+
2. Install dependencies: `pip install -r requirements.txt`
3. Start your MySQL Server (e.g., XAMPP, WAMP)
4. Execute `database/schema.sql` in your MySQL database to create tables.
5. Configure your database credentials in `config/database.py`.

## Execution
Run the application using:
`python main.py`

*Note: On the first run, the system will automatically create an admin user (Username: admin, Password: admin123).*
